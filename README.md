## Quick start

1. Run the portable app and select your player profile.
2. Use **Borderless or Windowed Fullscreen** in AoE4 for the overlay.
3. Check the dashboard or scout an opponent, then review synced matches in **My Stats** and **Data Studio**.

Windows is required for the full overlay and local-file features. RTSLytics reads public APIs and your own AoE4 files; it does not modify the game.

## Features

- Opponent scouting, public recent matches, and personal head-to-head history.
- Matchup counters, rating-based win odds, live APM, session record, and build-order widgets.
- Adaptive build coaching and post-game economy, timing, and performance review.
- Personal stats, sample-labeled benchmarks, matchup analysis, and filterable Data Studio.
- Civilization data, guides, and community build orders.

Written guides remain a work in progress. Community builds credit their authors and link to [AoE4Guides](https://aoe4guides.com/) in the app.
